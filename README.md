# PREDICTION DU CANCER DE SEIN


##  Contexte
Projet réalisé dans le cadre du cours de deeplearning, en 2025.

**Objectif** : L'objectif de ce projet est d'évaluer notre capacité à concevoir un pipeline d'apprentissage profond pour l'analyse d'**images** à partir d'une étude de cas réelle, depuis le traitement des données jusqu'à l'interprétation des résultats du modèle.

## Motivation

Le cancer du sein est le cancer le plus fréquent chez les femmes, et le carcinome canalaire invasif (CCI) en est le sous-type le plus courant. L’identification précise du CCI constitue une tâche clinique importante, qui permet d’évaluer le degré d’agressivité d’un échantillon. Pour identifier le CCI, on procède souvent à une biopsie afin de prélever de petits échantillons de tissu. Ceux-ci sont ensuite examinés par un pathologiste, qui établit le diagnostic. Au cours des dix dernières années, des outils d’apprentissage profond ont été développés pour accélérer le délai de diagnostic, grâce à des modèles automatisés qui analysent des images numériques d’échantillons de tissus afin de proposer un diagnostic. Cependant, plusieurs défis techniques subsistent, notamment pour obtenir des outils d’apprentissage profond plus robustes.


##  Technologies utilisées
- Python 3
- NumPy, Pandas, Matplotlib, pytorch
- Jupyter Notebook
